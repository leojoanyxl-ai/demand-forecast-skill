# 经营计划与决策规则

## 1. 先明确一个需要改变的行动

任务卡列出决策者、信息时点、经营期间、选项、约束与复核时点。例如，战略部门在制定明年预算时比较维持产能、加班、外协及延后投资。示例不是对所有用户的默认投资任务。

用户只要求行业研究时，输出行业判断及对应的经营条件，不虚构某企业内部参数。需要企业方案时，可先做一个有充分输入的具体决策，不强求同时完成所有经营优化。

## 2. 分市场的销售机会

`企业销售机会 = D × 国内可服务比例 × 国内可服务市场份额 + X × 出口可服务比例 × 出口可服务市场份额`。

两个份额的分母明确，避免把已按全市场定义的份额再乘一次覆盖比例。出口目的地受准入限制时，可服务比例不假定为100%。一个份额同时用在国内、出口的情况需要依据。

市场机会不等于预算目标或确定订单。销售计划考虑客户、产品、渠道库存、交付、价格与竞争；不能保证行业增长会传到企业。收入还需要对应销售价格和产品组合。

## 3. 库存与产能的确定性平衡

在同一成品边界、同一期间和单位下：

`净生产需要 = 计划销量 + 目标期末库存 - 期初库存 - 其他净到货`。

其他净到货包括已明确、未在自产重复计算的净入库；损耗、退货等按方向单列。若净生产需要为负，生产计划最低为零，并显示超过目标的库存，不能隐藏在负产量里。

`有效产能缺口 = max(0, 最低非负生产需要 - 本期有效产能)`。

`生产需要/有效产能`表示所需产能负荷；超过100%意味着当前能力不足，不是已经实现的产能利用率。随附脚本保留字段名 `capacity_utilization`，按此负荷含义解释。

有效产能已经扣减的良率和停机不重复折减。行业年度需求不能单独推导月度峰值、交期或产品线瓶颈。库存目标是用户输入时，标为目标，不称最优库存。

一次性备货且需求分布、边际缺货成本和过量成本可信时，才考虑报童模型：目标分位数为 `缺货边际成本/(缺货边际成本+过量边际成本)`。成本须在同一边际损益口径；长期补货、相关需求或产能约束不能直接套用一次订货结果。三情景不能直接代入为需求概率分布。

## 4. 比较经营方案而不直接宣布最优

| 方案 | 经济含义 | 应取得的数据 | 典型风险 |
|---|---|---|---|
| 维持产能 | 保留资金并承担潜在缺货 | 可交付销量、贡献毛利、现有瓶颈 | 销售流失、服务下降 |
| 加班或班次调整 | 短期增加供给 | 增量工资、良率、交期、许可约束 | 成本与质量、持续性 |
| 外协或合同产能 | 支付灵活性成本换取可逆性 | 报价、产能、质量、最低采购量 | 履约、供应商和切换 |
| 新建或扩产 | 不可逆投入换取长期能力 | 建设期、增量现金流、残值、融资 | 需求落空、过剩、技术淘汰 |

有可比成本时，比较增量利润或现金流。投资可按明确折现率计算 NPV 并做情景敏感性；不可逆性和等待新信息的价值需要讨论，但没有期权模型时不给“已算出实物期权价值”的结论。不同方案投资时点、寿命与服务能力不同时保留差异。

只有产能缺口而缺少成本时，建议“对缺口询价、核验订单与交期，再比较方案”，不要直接建议扩建。阈值来自能力边界、成本转折或使用者容忍度，而非任意整数。

## 5. 决策摘要

每项建议四要素同时出现：

- 建议：谁在何时调整什么，或等待什么信息后行动。
- 理由：需求与经营核算中哪些证据支持，以及备选方案的取舍。
- 适用条件：份额、价格、订单、能力及情景哪些前提需要成立。
- 风险：最可能使建议失效的变化、观察指标、责任人及复核时点。

先确定结论对什么敏感，再画图。展示需求情景、销售机会、生产需要、能力缺口与行动的联系；不要把乐观需求自动设为目标产能、悲观需求自动设为安全库存。

## 6. 随附核算工具

`scripts/planning_bridge.py` 读取 CSV，计算同口径的分市场销售机会、库存平衡与产能缺口。它只做确定性核算，不拟合行业数据或估计最优计划。

脚本仅需 Python 标准库，命令路径相对 Skill 目录：

```text
python scripts/planning_bridge.py --input assets/planning-input.example.csv --output 核算结果.csv
```

样例每个数量字段都采用“万辆”，全部数值是教学假设。输出保留该标记；替换为真实数据时需同步修改来源及性质。缺份额、库存等参数的行保留诊断，不自动填零。无出口的真实适用情形应显式填写出口0，而非留空。
