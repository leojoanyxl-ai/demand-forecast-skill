# 完整运行与统一口径

## 运行

在Skill目录双击“运行完整分析.cmd”，或执行：

```text
python -B scripts/run_full.py --company assets/company-input.csv --open
```

默认读取规范化CSV与JSON，不需要联网或Excel库。每次新建“运行记录”子目录，保留输入和结果，不覆盖上一轮。运行需要Python 3；启动器优先查本机已有环境，再查py/python。

## 统一的输入职责

| 输入 | 唯一职责 | 修改方式 |
|---|---|---|
| [nev-evidence.json](../assets/nev-evidence.json) | 独立年度/累计值、宏观事实及来源 | 年度日期和定义核对后更新；样本数由数据计算 |
| [nev-monthly.csv](../assets/nev-monthly.csv) | 同体系汽车销量、新能源销量及各自出口 | period为YYYY-MM、单位万辆；有发布日期、原链接、reported/derived性质；推算附公式与另一来源 |
| [auxiliary-monthly.csv](../assets/auxiliary-monthly.csv) | 产量校验、公共桩条件及原工作簿定位 | 保留单位、角色、原文件指纹；未给发布日期的辅助项不冒充已做实时驱动检验 |
| [economic-parameters.json](../assets/economic-parameters.json) | 原始弹性校准目标、中央值、范围、网格及解释 | 所有中央点和边界自动进入组合；模型内部TCO/logit系数不在这里直接混填 |
| [nev-settings.json](../assets/nev-settings.json) | 本次路径、原始弹性目标或成本覆盖 | 只覆盖需要改的项，并保留依据；旧parameter_overrides接口拒绝混用系数 |
| [nev-economic-scenario.example.json](../assets/nev-economic-scenario.example.json) | 模型结构、代表成本及政策传递示例 | 不维护第二套年度历史或数值行为系数；经统一入口补齐后才能计算 |
| [company-input.csv](../assets/company-input.csv) | 待填的真实企业参数 | 份额、覆盖、库存和有效产能保持空白，缺项列出，不填成0 |

替换月度文件时可用 `--monthly 路径`，替换辅助文件用 `--auxiliary 路径`，参数表用 `--parameters 路径`。按随附CSV列名导出/整理；本入口不会声称能自动识别任何Excel中的统计口径。

国内汽车代理=汽车总销量−汽车出口；国内新能源代理=新能源总销量−新能源出口；同月D+X=Q。四条数据均为中汽协厂家统计体系，不能掺海关汽车出口、企业全球销量、零售或产量。目标与辅助指标不因同属一个行业就放入同一回归。

月度当月值与独立年报/累计值之和另核。超出所列舍入精度的差额保留，不能缩放、造“其他”或猜测修订原因来配平。年度校准与月度基准使用各自声明版本；差异未核清前不将月度序列冒充与年度完全重述一致的历史。

## 弹性转换

用2026桥接国内份额p0作为局部转换锚点。代表车型计算κ_N、κ_I，即购价对广义持有成本的局部对数导数，包含税费处理。成本和残值结构可能使κ大于1，不能预设其小于1。

`κ_M = p0×κ_N + (1−p0)×κ_I`

`总市场成本系数 ε_C = 总市场购价弹性 / κ_M`

`新能源选择系数 β = (ε_C×p0 − 新能源购价弹性/κ_N)/(1−p0)`

`补能logit系数 γ = 固定M的新能源销量补能弹性/(1−p0)`

因此原始目标、模型系数和隐含弹性是三列不同数值。未来份额p_t变化时，补能局部销量弹性为 `(1−p_t)×γ`，不强行保持恒定。新能源购价响应同时有M和技术选择两条渠道，转换不能只套份额导数。

数学转换不解决经验迁移：美国购价弹性、中国全车型成本、EV注册量、终端销量和Armington原产地替代并不等价。世界银行充电端口0.32为其OLS结果量级。当前参数仍是外部文献量级下的条件校准；范围不是统一估计区间或置信界。

## 亲自修改

例如在用户设置的 `scenario_overrides` 的基准对象填：

```json
{"real_income_growth":[0.06,0.05]}
```

两项依次为2027与2028。收入改变相对参照的国内总市场，不直接改变出口；`foreign_demand_growth`改变出口；`nev_real_price_growth`经总成本和技术选择影响国内。已公告2027税制不随情景任意改动，2028接续仍为条件。

在 `economic_parameters` 中覆盖原始补能销量弹性目标：

```json
{"infrastructure_sales_elasticity":{"central":0.4,"interpretation":"本次规划压力目标，未经本样本因果识别"}}
```

中央值超出原范围时同步提供range/grid；程序检查数值范围，并把新的中央值与边界纳入实际网格。改代表成本后会重算κ及选择系数，不沿用旧映射。

## 验证与状态

年度参照链与月度目标基准分别报告，不拼成一个准确率。月度比较朴素与季节朴素，按h=1/3/12/24从最后实际月份起计；检查信息日和迟发的推算来源，跳过不合法起点。实际预测日历提前期受发布日期影响，不能把h理解为数据发布后完整的同等月份。

每个方法、期限同时列国内、出口和总量的MAE、WAPE、方向偏差，另列分支绝对误差与抵消诊断。相邻/重叠窗口不等于独立年度。年度收入路径相对参照恒为1时，该年度检验不验证收入弹性。月度基准也不能替代价格、政策、自变量路径或企业计划的完整检验。

参数网格组合数、预测行数、样本年份和观察数从本次输入生成，不在报告固定写死。它们是不同统计对象，不能把网格行数写成历史样本量。

`parameters_unfilled`指缺数值；`parameters_not_locally_identified`指未由本项目识别的行为系数。两者可以一个为空、另一个非空。企业`ok`只表示给定输入能核算；教学演示和真实业务验收分开。

用[company-input.example.csv](../assets/company-input.example.csv)可演示完整经营算术，须显著保留教学标记。运行 `python -B scripts/test_unified.py` 检查月度边界、时间泄漏、弹性有限差分、网格覆盖、误差抵消和完整流程；测试通过不等于真实预测与业务验收通过。
