# 数据证据与可用性规则

## 1. 权威性、真实性和充分性分别判断

来源机构权威，不代表摘要数值已核实，也不代表它能用于本次模型。每项至少记录：指标/定义、数值、单位、地区、统计期间、频率、原始发布者、原始URL、发布日期、获取日、版本、原文件单元格或页码、处理方式、使用环节。

来源优先为原始统计发布、主管部门、行业组织和企业正式披露。数据库记录提供者、原始发布方与提取时间；研报和新闻作为发现线索，有原文时回查。行业组织数据不写成政府直接统计；政府转引行业组织时保留该说明。

将状态写成具体事实：本轮打开原文核验、仅有机构名尚未核验、数据库导出待回溯、用户假设、公式推算、教学虚拟。禁止凭来源等级赋予没有依据的真实性概率。

## 2. 需求侧最低数据清单

| 信息 | 公共/内部 | 支持用途 | 缺项时怎么处理 |
|---|---|---|---|
| 同口径行业历史需求与总市场 | 公共为主 | 基准预测与份额边界 | 无目标历史时只做结构/条件情景 |
| 国内、出口及必要目的地 | 公共为主 | 市场分支与政策传导 | 分支不足则保留总量模型，不倒造分支 |
| 相对成交价、购置与使用成本 | 公共/内部均可 | 需求替代与价格条件 | 标价不冒充成交价；缺序列则不估价格弹性 |
| 收入、就业、融资、下游活动 | 公共 | 总市场和支付能力 | 单期摘要只作背景，不能复制成历史样本 |
| 政策、技术、替代与事件 | 公共/内部 | 路径变化与结构风险 | 区分已实施、已公布、假设及未知接续 |
| 企业可服务范围、份额、订单 | 内部/部分披露 | 销售机会与预算 | 不计算精确企业销售量，或使用标注的教学参数 |
| 库存边界、在途、提前期、服务目标 | 内部 | 备货、生产与库存 | 年度需求不足以推导最优月度安全库存 |
| 有效产能、切换/加班/外协成本 | 内部 | 弹性产能方案 | 只报告缺口与需要询价的信息 |
| 投资现金流、建设期、融资与约束 | 内部 | 项目比较与时点 | 需求增长不构成投资批准依据 |

## 3. 必做质量检查

- 日期重复、缺失、断点、修订和异常，与发布日期对应。
- 单位与数值尺度分别查看。`0.282` 使用百分比格式为 `28.2%`；`0.0282` 是 `2.82%`。不要通过改单元格显示掩盖十倍的数值错误。
- 官方同比与当前序列自行计算同比分别保存；基数修订可以造成小差异，不能直接用“修订”解释十倍尺度差。
- 流量可按期间加总，期末存量不能逐月相加；新增数量同比下降不等于存量下降或存量增速为负。
- 产量与销量、厂家批发与零售、出口出货与海外消费、国内与含出口边界分别识别。
- 充电设施的“枪、桩、站、功率、电量”口径分别保留；存量增加可能既是需求条件又是已有需求的结果。
- CPI 大类指数不自动等于燃油价格，技术成本不自动等于成交价，GDP 不自动等于目标客户可支配收入。
- 季度或年度数据插值不增加独立信息，需在训练窗口内处理并保留标签。

## 4. 降级和停止规则

以关键字段和用途判断，不能用任意“已收集80%”阈值代替。

1. 目标序列、单位和口径可核对，但驱动序列不全：可做朴素/简约预测和明确假设的情景，不能声称已做驱动回归或因果分解。
2. 只有年度需求：可做年度规划，不能据此给出可靠月度库存和峰值排产。
3. 缺企业内部数据：行业分析继续，经营部分提供补数表、条件规则或清楚标记的教学示例。
4. 目标口径严重冲突或关键来源无法核实：暂停受影响的数值输出，提供候选口径、补源与恢复条件。

每次结论写清“可做什么、还不能判断什么、最先补哪项”。允许使用者选择补数或在明确条件下继续；选择记录进入运行快照。

可靠总量与细分可分别判断。缺一个可选驱动不必停止总量基线；国内/出口或用途不全时，不能将部分覆盖量称为完整需求。缺项用空值与原因表示，真实零需要覆盖和来源依据。

## 5. 虚拟与修订数据

虚拟数据逐文件标注教学用途、生成方法、变量关系、取值依据和随机种子（如使用随机数）。输入模板用空值表示缺项，不用虚构真实公司内部资料。虚拟样本验证的是流程或计算，不代表真实预测精度。

原始数据不覆盖。修订版保留原值、新值、定位、依据、操作者和日期。数据文件与快照指纹不一致时标明版本未对齐，不能直接断言内容被篡改。旧绝对路径换成实际交付的相对路径，并检查目标存在。

## 6. 公开数据补数与转换

先列影响结论的缺口及其阻塞的公式，再在用户已有访问范围内查找。依次查看已给材料、原始发布机构和可替代原始来源；有明确新线索再继续，不无限搜索。正常可访问的公开数据由 AI 先尝试取得；业务定义、内部数据或新增访问授权才向用户询问。

补数记录使用具体状态：仅定位到来源、已取得原始值、已完成口径核验、需转换、访问失败或口径不符。保存缺口、用途、链接/表号、发布日期、获取日、版本、取得范围、采用决定及失败原因。检索摘要不是原始数据表，不将机构名称当作取数成功；未取得的值不能按新闻图形估填。

转换另存“原指标/数值→目标指标→公式/系数及来源→适用期→结果→残留限制”。单位换算不改变统计实质；销售额转数量需匹配的产品价格与结构；价格指数不是价格水平；地区扩展、原料/成品和分类变化需要可核查映射。累计转当期需同定义、同修订基础并处理年初重置；同比增速不能差分成当月量。

历史验证中只用当时可见的补数与转换依据。后续修订版与当前版可以另作敏感性对照，不能无说明地覆盖训练窗口信息。

## 7. 分项汇总与覆盖检查

先定义本次一个汇总视角中的最小互斥单元，例如“市场×车型×交易阶段”。父级总量与子项不同时参加求和，按用途与按地区的两张表是不同视角，不能再将两个总计相加。互斥、穷尽需要定义和来源支持，数值恰好相等不能证明。

进入同一次加总的每条记录明确：单元ID、产品/市场、时期与频率、日历/年度基础、单位、数量/金额及存量/流量、交易阶段、实际/估计/预测/假设、情景、点值/均值/分位数、版本与信息截止。先核验适用字段，不能仅因单位和标签相同便求和。已观测月份与剩余月份预测可以构成全年估计，但全年结果须标“估计”，不能标全年实际。

逐期、逐情景检查：

- 计量和时间基础一致；流量缺月留缺，期末存量不相加。比例、单价与均值按匹配分子分母重新计算。
- 最小单元不重叠，已在总量中的出口等不再加一次。已知不互斥的资料无法靠改ID变成可加。
- 分项不全则报告已覆盖小计；独立总量可靠但细分缺失时，另列“尚未分配差额”，不自动归为“其他”需求。
- 有依据的估计或明确假设可以纳入条件情景，但保留分项性质和对总量的影响。不能因算术相符而升级数据或业务验收状态。
- 独立总量与分项和的差异保留原值及来源，不强行配平。容差依据原始精度与舍入规则；整数精确计量不能借宽泛相对容差忽略真实差额。

先对相容的分项路径求和，再计算增长率或总量分位数。缺少联合关系时说明相关性假设，不直接相加P10/P90或把所有分项的单独最优条件拼在一起。现有脚本的D+X计算不替代原始账户和口径核验。

## 8. 收到既有预测时的版本保存

先按用户要求保留原文件或原文、来源位置与文件指纹；新分析另存版本。至少区分：

| 字段 | 含义 |
|---|---|
| received_at | 本次接收时间，含时区；只能作为本次记录时间 |
| forecast_issued_at | 原预测发布日期；未提供时标未知，不用接收日代替 |
| information_cutoff | 原预测当时使用的信息截止日/期间；未知则留缺 |
| target / periods / values | 原指标边界、单位、逐期原值及实际/预测性质 |
| original_assumptions | 原情景、驱动、参数、季节/周期和验证说明；未提供就如实记录 |
| parent_version / changes | 新版关联哪个旧版，补了什么数据、改变什么假设、由谁提供 |

用户仅要求保存时到此完成；要求比较时先核对定义、信息期和假设，不自动重估。更新信息后的差异不能称为同信息条件下的预测能力胜出。后续同口径实际值发布后，另存实际数据版本与误差计算；不得回改原预测使其贴近实际。
