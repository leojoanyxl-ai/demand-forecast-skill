# 预测方法、情景与验证

先依据 SKILL.md 的数据可用性选择路线，再读取本参考中适用的部分。回归、VAR/VECM 是候选工具，不是所有任务的默认必经步骤。行业数据只有短年度序列时，优先考虑朴素基准、总市场与份额分解或透明的条件情景。

## 方法选择记录

| 数据与业务条件 | 候选方法 | 必须披露的限制 |
|---|---|---|
| 只有少量年度销量 | 朴素基准、简约趋势、存量更新或总市场×份额 | 参数少；长预测期限验证不足；趋势不解释经济因果 |
| 连续分期销量、季节性明显 | 季节性朴素、指数平滑、适当的单变量模型 | 旺淡季、节假日、结构变化；不凭插值制造样本 |
| 销量与相对价格、收入等能按发布时点对齐 | 动态需求回归、适当正则化 | 自变量未来路径、内生性和样本规模 |
| 少数驱动相互影响且样本和诊断支持 | VAR/VECM或其他联合预测 | 滞后参数规模、平稳性/协整、条件路径一致性 |
| 新政策、替代加速或重大事件无可识别历史 | 情景假设、压力测试、结构化判断 | 叙事、幅度来源、传导限制；不声称已估计因果效应 |

先给简单基准，再比较增加机制或复杂方法的增益。目标变量、频率、预测期限和数据版本一致才可比较。无稳定改进时保留简单方法。政策改变只影响相关的国内或出口分支；以模型加总恢复行业总量。

## 按用途设计验证

在查看模型比较结果前填写[用途与验收计划](../assets/validation-plan-template.md)。首先确定谁会据此改变什么安排、错估的后果和实际提前期；最后一个已发布实际期之后尚未观测的基年部分也是预测，不能因为报告标题写“2027”就只检验一年提前期。基年桥接、自变量未来路径和经营映射分别标记是否验证。

业务标准来自使用者容忍度、服务目标或有依据的错估成本。未知时继续探索，不能自行定“WAPE低于10%即合格”等通用阈值。高估与低估的代价不同且已有可靠业务依据时，可补充非对称损失或对应分位数检验；库存等目标还受提前期、服务水平和成本影响，年度WAPE不能独立验收月度经营方案。

分别记录模型相对比较和用途判断。优于朴素基准只说明这组样本和期限下的相对结果，不代表精度已经能支撑产能承诺。总量、国内/出口、不同期限可以有不同状态，使用“已按所列标准验证、探索性基线、条件测算、暂不支持数值输出”，并列明依据与未覆盖环节。

计划在事后才补写或曾反复查看留出结果时如实标记。失败后记录简化、补数或转为条件测算的选择；不调宽阈值把失败改成通过。

## 季节、周期、趋势与结构变化

按任务和数据需要诊断，不要求每次预测都识别一个行业周期：

| 现象 | 需要区分的机制与证据 | 对预测的实际处理 |
|---|---|---|
| 季节/日历重复 | 月份、春节、工作日、季末及其稳定性 | 比较季节基准、日历项；只有年度数据不声称已估计月度季节性 |
| 多年景气波动 | 相关需求活动、购买更新批次、融资等共同变化及持续性，不能只看单个销量涨跌 | 证据支持时比较阶段持续/转换条件；阶段、转折时间或概率未知时留缺 |
| 长期趋势或技术替代 | 人口、采用率、存量、偏好等长期变化及合理边界 | 作为趋势/结构机制，不将渗透率上升直接命名为周期复苏 |
| 一次冲击或结构断点 | 政策、准入、统计变更、技术事件的时点及渠道 | 分暂时扰动、跨期迁移和持续制度变化；不自动重复成下一轮周期 |

指标需说明领先/同步/滞后关系、发布日期和可反驳的证据。需求低迷同时价格下降可能反映不同机制，不用“处于周期底部”替代分析。不能仅凭观察年份数宣称经历完整周期，也不按固定间隔推算必然拐点。

若实际建立周期或阶段调整，在每个训练窗口内重估趋势、滤波、阶段标签和参数，不能使用含未来信息的双边平滑或全样本事后转折。历史支持时分阶段及转折附近报告误差、样本量和重叠；缺少转折样本就明确跨阶段能力未经验证。历史冲击重放属于压力情景，不等于已经预测下一次转折。

仅处理季节性的模型称“季节基线”；周期只进入外设条件时称“含周期条件的情景测算”；只有实际计算并有相应检验的部分才称周期调整。当前新能源汽车原型尚未识别周期状态或估计阶段转换概率，不能因增加本说明而升级其能力表述。

### 2.2 建立可解释的需求回归

数据和机制支持驱动回归时，可选用简约的多元回归或动态回归：

\[
g(Q_t)=\alpha+\sum_{l=1}^{r}\phi_l g(Q_{t-l})
+\sum_j\sum_{k=0}^{L_j}\beta_{jk}f_j(X_{j,t-k})
+\gamma'D_t+\varepsilon_t
\]

其中 Q 为需求代理指标，X 为驱动因素，D 为季节、节假日或有依据的事件变量；g、f 表示适合数据的变换。不是所有模型都需要全部滞后或当期项。

- 对数仅适用于其定义域允许的变量；差分、标准化等处理需记录且在预测时一致应用。
- 非平稳水平序列直接回归可能形成伪回归。根据趋势和协整关系使用差分、误差修正等合适形式。
- 关注共线性、残差自相关、异方差、系数跨窗口稳定性，以及预测时自变量是否可获得。
- 残差有动态结构时，考虑增加合理滞后或使用带 ARIMA 误差的动态回归；稳健标准误本身不能解决动态预测偏误。
- 只在相应函数形式下解释弹性；含分布滞后或需求自回归时，区分短期与长期效应。

样本不足时减少变量、合并高度相关指标，或使用有明确验证依据的正则化。不能只按 p 值筛选变量，也不能凭较高 R² 认定预测有效。

### 2.3 识别主要驱动与解释边界

结合行业机制、系数稳定性、时间顺序验证中的增量预测价值和情景敏感性，确定核心驱动。区分：进入主模型的因素、仅作为情景设定的因素、现有数据无法量化的因素。

价格、政策响应、基础设施和竞品销量可能与需求相互影响。普通回归只提供条件关联，不直接证明因果；格兰杰检验也不能替代因果识别。需要政策因果或价格弹性结论时，另行评估识别设计和可用工具变量；没有识别证据时保留限制。

样本中没有类似新技术或重大事件时，不能虚构其回归系数。将其作为单独、有来源的情景假设或压力测试，避免与模型已有影响重复计算。

**本步产出：**驱动因素表、入选与剔除理由、需求模型规格、参数及解释边界、待提供未来路径的全部自变量清单。

## 驱动变量未来路径：VAR为可选工具

### 3.1 为每个自变量安排未来值

先建立路径责任表，确保已选需求模型右端的每个变量均有处理方法：

| 变量类型 | 优先处理方式 |
|---|---|
| 相互关联且样本可支持的宏观或产业连续变量 | 小规模 VAR；存在适合的协整关系时考虑 VECM |
| 已公布实施日程的政策或税率 | 按明确安排设置路径，未确定的后续安排另设情景 |
| 用户掌握的产品价格、促销、渠道规划 | 使用用户方案并注明来源，配套备选路径 |
| 自身及竞品价格、替代品指标 | 依据可得数据单独预测、纳入合适的联合系统，或显式设置情景 |
| 技术渗透、成本下降、重大事件 | 有证据的趋势/扩散模型、政策目标情景或压力假设 |
| 季节、日历及已知事件 | 按未来实际日历构造，不以 VAR 预测 |

计划目标属于假设，不自动当作确定会实现的实际值。不得默认未来价格不变、竞品销量不变或政策永久延续而不披露。

### 3.2 估计基准路径

对适合联合外推的因素建立：

\[
X_t=c+A_1X_{t-1}+\cdots+A_pX_{t-p}+u_t
\]

这里的 X 是需求模型的解释变量；进入 VAR 后是系统内共同建模的变量，并不因此满足严格的经济外生性。

执行要求：

1. 根据平稳性、协整和确定性项选择变换与模型。VECM 需要相应的协整证据，不能因任一变量不平稳就直接改用 VECM。
2. 依据有效样本量设置合理的候选滞后范围，结合 AIC/BIC 与时间顺序回测选择。
3. 报告变量数 K、滞后阶数 p、有效样本和每方程参数规模。仅含常数的 VAR 每个方程有 Kp+1 个回归系数；增加季节或其他项时继续计入。
4. 检查稳定 VAR 的稳定性与残差动态。VECM 按其协整和动态结构检查，不能机械套用平稳 VAR 的判断。
5. 参数过多、共线或结果不稳定时，依次考虑减少变量/滞后、适当聚合频率、有条件采用 BVAR，或改用简约单变量模型。记录降级理由。
6. 将差分或对数差分预测正确还原到需求模型需要的尺度；累计量、同比和存量各按其定义还原。

选用驱动回归路线时，保持两层预测的一致性。若确需将目标销量纳入联合 VAR，说明这是联合系统预测方案，使用条件预测直接得到需求；不能把该方案与原来的两层预测当作独立证据重复计算。

### 3.3 构建基准、乐观与悲观情景

以目标需求的有利或不利条件定义情景，不以每个变量数值的高低定义。先给出经济叙事，再给出逐期路径。

- 基准：依据截至预测日的信息和有支持的中央假设形成。模型外推与已知安排不一致时，解释如何调整。
- 乐观：一组相互协调、对需求更有利且有依据的条件。
- 悲观：一组相互协调、对需求更不利且有依据的条件。

每个情景记录：调整变量、方向、幅度、启动时间、持续时间、恢复路径、依据及实现条件。偏离幅度可参考历史预测误差、类似事件、可信外部预测或明确规划；无法证实的幅度标为分析假设，并做敏感性分析。

不能把所有变量统一上下浮动同一百分比，也不能将政策目标直接视为必然兑现。若模型算出的情景次序与叙事不符，检查机制、交互和假设，解释原因；不得事后排序或修改结果以迎合标签。

对系统内部分变量施加未来路径约束时，使用条件 VAR/VECM 预测，让未约束变量随之更新。仅替换常规预测的一列不等价于条件预测。脉冲响应只可用于明确识别和定义的冲击分析，不能默认用冲击响应叠加替代任意路径条件预测。

分别独立设定多条路径时，检查它们是否经济上协调，并标明这是外设情景，不能声称已保留 VAR 的全部联合分布。没有依据时不给三个情景分配实现概率。

**本步产出：**全自变量路径责任表、基准外推结果、模型诊断、三种情景的逐期输入表及假设来源。

## 目标行业需求预测

### 4.1 逐情景、逐期预测

将各情景的自变量路径输入需求模型：

\[
\hat Q^{(s)}_{T+h}=\hat f\left(\hat Q^{(s)}_{T+h-1},\ldots,
X^{(s)}_{T+h},X^{(s)}_{T+h-1},\ldots,D_{T+h}\right)
\]

s 表示情景，h 表示预测步长。若有销量滞后，使用同一情景此前的预测递推；已知历史滞后仍使用历史值。按模型变换定义还原结果。

保留决策需要且数据支持的颗粒度。报告年度总量时，对分期销量求和，不以月均值代替年销量。若做了月度拆分，区分真实月度模型与依赖季节权重的分解。

对长期渗透与替代明显的行业，检查总市场、存量更新与合理上限。必要时将“总市场 × 渗透率”或扩散模型作为备选；采用何种方法由行业机制和验证结果决定。不得让线性外推长期产生负销量或超过逻辑上限，也不得仅靠事后截断掩盖模型失配。

### 4.2 验证完整预测链

在可支持的历史窗口中做滚动或扩展窗口回测，预测步长尽量匹配用户用途。变量筛选、缺失处理、变换和模型选择只能使用各训练窗口的信息。

每个预测起点均重建“自变量预测 → 需求预测”的流程，并与季节性朴素预测、简约单变量模型等合理基准比较。使用真实未来自变量得到的结果只能作为“自变量已知”诊断，不能代表可部署预测精度。

报告合适的 MAE、RMSE、WAPE/MASE、累计量误差和方向性偏差，并说明样本与分母；有零值或接近零值时不依赖 MAPE。若有预测区间，检查历史覆盖率及宽度。

训练窗口无法覆盖目标长期预测期限时，明确长期表现未经充分验证。无法获得历史数据版本时，可使用当前版本回测，但说明可能存在数据修订带来的乐观偏差。

若复杂模型没有稳定优于基准，优先使用简约模型，或在充分验证后组合模型；保留驱动分析作为情景解释，不以复杂度代替可靠性。

### 4.3 传递预测不确定性

区分三个概念：不同假设造成的情景差异、给定情景下的需求预测区间、参数估计的不确定性。三种情景的最小/最大值不是统计分位数。

在实现允许时，通过联合模拟、适合时间依赖的 bootstrap 或贝叶斯后验预测，将驱动路径、需求扰动及可处理的参数不确定性传播到最终销量。保留相关变量及跨期误差的依赖；条件情景中被固定的路径不能又被无条件随机化。两层残差存在相关性时，应联合处理或明确简化限制。

无法完成完整传播时，只报告实际计算的条件区间，并明确未包含哪些不确定性。不得把只输入自变量点预测得到的区间说成完整风险范围。

对数预测取指数通常对应中位数而非均值；明确点预测统计量。年度区间应先对每条模拟路径的月度销量求和，再计算年度分位数，不能直接把各月分位数相加。

**本步产出：**逐期情景预测、定义清楚的区间、回测对照、重要敏感性与模型限制。
