# 用途与验收计划

在查看本轮模型比较结果前填写适用项。没有依据的项写“未提供/尚未确定”；已看过结果后补建的计划，注明是事后整理，不声称为预先约定。

| 项目 | 本次记录 |
|---|---|
| 决策者、决策日期与可调整行动 | 谁将依据预测改变什么安排 |
| 目标与统计边界 | 总量/国内/出口或用途，单位、市场、交易阶段、频率 |
| 信息截止与有效提前期 | 最后已发布的实际期；基年未观测部分、全年桥接及计划期；不能只按年份标签计算h |
| 错估的后果 | 高估/低估分别影响什么；有可靠成本时记录非对称损失，缺成本时保留方向，不捏造金额 |
| 比较基准与样本 | 朴素/季节基准等；相同起点、实际期和期限；注明重叠 |
| 训练、选择与检验设计 | 变量、清洗、参数与周期判断在哪些信息窗口确定；留出期是否已被查看 |
| 评价指标与权重 | 适用的MAE/WAPE/MASE、偏差或累计量误差；权重依据及零值处理 |
| 业务通过标准及依据 | 来自使用者容忍度、服务承诺或成本测算；未知时只做探索比较，不设通用10%阈值 |
| 稳定性与区间要求 | 相关期限/市场/状态要检查什么；样本不足时哪些无法检验 |
| 失败处理 | 简化方法、仅保留可用总量、转为条件测算或停止受影响的数值结论 |
| 实际执行与未覆盖环节 | 方法、数据版本、运行记录；桥接、自变量路径、企业映射是否一并验证 |

结果分别填写：

| 对象与用途 | 相对比较结果 | 业务标准是否明确并达到 | 未验证风险 | 可使用状态与下一步 |
|---|---|---|---|---|
| 按目标/市场/期限分别列 | 胜出/未胜出/不能比较 | 通过/未通过/未知，并列证据 | 不由其他模型成绩替代 | 已按所列标准验证/探索性基线/条件测算/暂不支持数值输出 |

计算检查、相对胜出、达到指定业务标准和用户最终批准是不同判断。不能凭一个“通过”同时代表这四件事。即使某模型优于朴素基准，样本量、长期表现或业务损失仍可能不足以支持确定的经营承诺。
