# 2015—2025完整11年重算与版本回测

本轮日期2026-11-04；案例信息仍冻结在2026-11-03。主案例为新能源汽车，ABS继续作为迁移试验。原工作簿保留，SHA-256与最初快照一致；没有更改实际数值以改善成绩。

## 这次实际做了什么

1. 冻结原表2015—2025共11年实际，以全部11年拟合总体新能源份额趋势，2026E不加入拟合；默认运行入口已接入主总量重算。
2. 原版2027、2028未加额外经济偏离的基准重现为2179.22和2480.21万辆。相同资料与公式本就应复现相同结果，不强行制造“迭代差异”。
3. 独立国内／出口模型继续使用可核同口径较短分支史，作为结构与经济条件校验。11年总量和分支预测不强制配平，保留方法分歧。
4. 经济条件敏感性沿用原有机制和参数表，以明确结构权重将分支相对无增量条件的比例迁移到总量参照。此权重迁移是规划假设，完整经济乘数未历史验证，不与基线回测混为一谈。
5. 重跑原版扩大年度样本、同起点V1/V2、月度适配及候选分支，另对2023—2025做只知道前三季度的全年桥接回放。
6. 2026全年可以预测补齐，但没有全年实际，所有2026E和未来Q4都单列，不参与实际评分。

## 同学指出的抵消确实存在

原参照链从2024预测2025，国内高估136.81万辆，出口低估133.10万辆，总量仅高估3.71万辆，约98.63%的分支绝对误差被抵消。这里是国内与出口，没有进口序列，不能称“进出口误差”。

## 第一版和改进版横向比较

在同样2023—2025三个不同实际目标年、同样一年提前期下：

|方法|总量WAPE|解释|
|---|---|---|
|V1原版总量|约3.16%|使用原定2015起扩展历史窗口|
|V1相同分支年份窗口控制|约7.07%|改变历史窗口后的控制实验，不称原版原样|
|V2年度参照链|约5.29%|同一目标与起点，仍是参考趋势与朴素出口，不是完整经济链|

V2在这个共同样本的总量成绩比V1差，不能宣称整体准确率提高。控制实验也说明历史窗口本身会影响结果，不能把所有差异都归给经济机制。

原版再扩大到2020—2024起点，1年期有5个不同实际年份，WAPE约10.53%；2年期4个不同实际年份，WAPE约23.15%。它与晚期共同样本不能直接比优劣，只能说明方法跨时期并不稳定。

## 月度比较扩大了验证，但没有冒充原年度完整模型

同一57个月资料、至少24个月训练，比较V1总体份额思想的月度适配、V2国内／出口适配、训练内独立选模候选及季节朴素。规模、分支、期限、月度绝对误差同时报告，派生来源过晚的起点会跳过。

未来1—12月累计量的共同可用起点21个，按窗口末年涉及2024—2026；都是已发布的实际滚动窗口，不代表取得2026日历全年。V2月度适配出口WAPE约45.92%，独立分支选模候选约41.65%；候选总量WAPE却从V2约6.71%变成约7.92%，国内也未改善。部分分支改善不等于整体胜出，候选未被提升为正式经营预算。

“只更新出口、国内固定V2”的额外对照用于解释抵消变化，属于看过初步结果后的研究。所有本轮比较均为当前版本回顾分析，窗口重叠、修订历史未恢复，尚非独立封存的前瞻验收。第一版没有独立出口模型，不能为它编造一个分支预测。

## 桥接怎样检验

分别对2023、2024、2025，仅使用各年前三季度和上一年同期／全年，估计该年国内与出口再加总，与真实全年比较。三个目标年桥接WAPE约为国内4.36%、出口10.57%、总量2.71%。年度和月度来源修订差异仍保留。这验证桥接自身，不证明后续两年政策情景准确。

## 国内和出口补充了什么证据

- 2026年前三季度国内新能源846.6万辆，比2025同期947.0少100.4；出口400.6比175.8多224.8，总量只净增124.4。该分解显示总增长掩盖结构分化，不能当作因果贡献。
- IEA2025、2026贸易分析支持目的地、品牌及海外生产变化需要分开；未将IEA电动乘用车与CAAM全车型销量硬拼成样本。
- 欧委会2024措施的对象为中国来源BEV，不直接覆盖全部PHEV、全车型与全部出口目的地。
- 商务部2025-09-26公告说明指定纯电动载人车辆2026-01-01起实行出口许可证管理。它补强准入渠道论证，不被擅自变成数量损失系数。
- 找到早期出口资料后检查到口径差异：流通协会贸易分析列2021新能源出口58.8万辆，与厂家口径31万辆不同。没有为了凑更长分支史而混接；仍需目的地×动力类型、价格、库存、终端登记和口径衔接资料。

## 怎样运行与汇报

默认完整入口：`python demand-forecast/scripts/run_skill.py --industry nev --output-dir 一个新目录`。运行后先看主页面及“11年总量三情景.csv”，原“分支经济情景与经营核算.html”继续作为独立校验。原“三情景结果.csv”保留分支结果用于历史追溯，不是新11年总量文件。

单独重新跑验证：`python demand-forecast/scripts/version_backtest.py --output-dir 一个新目录`。该命令输出逐条、汇总、抵消、桥接、2026估计和输入快照。

可以汇报：我们采用11年总量史重算，并通过真实回测发现新版并非在所有指标上更好；之后补上分支、期限和桥接诊断及出口候选，保留失配。当前能够证明的是验证完整度和问题定位能力提高，尚不能证明完整经济预测精度稳定提高。下一步应补分层直接驱动和真实前瞻检验，而不是编造实际或挑选最好起点。
